PhoneClean Android APK
======================
File: PhoneClean.apk  (isi folder mein)

Install:
1) APK phone pe copy karo (USB / WhatsApp / Drive)
2) Phone: Install unknown apps Allow
3) PhoneClean install + open
4) Allow files → All files access ON
5) Device / SD / Both → Scan
6) WA Img / WA Vid / folder → Search / Duplicates / Delete / Copy

USB se laptop PhoneClean bhi pehle jaisa chalega.
